Enhancement Overview

The Category Two enhancement demonstrates skills in algorithms and data structures through the addition of a personalized trip recommendation feature to the Travlr Getaways full-stack web application.

For this enhancement, I developed a weighted scoring algorithm that evaluates available trips based on user preferences for resort, maximum price, and maximum trip duration. A matching resort receives three points, a trip within the user's maximum price receives two points, and a trip within the maximum desired duration receives one point. Trips that do not match any criteria are removed, and the remaining recommendations are sorted from highest to lowest score.

The enhancement also introduced structured data through the TravelPreferences and TripRecommendation interfaces. These structures organize the user's preferences and associate recommended trips with their calculated scores and matching criteria. The completed enhancement demonstrates how algorithms and data structures can be applied to solve a practical problem while preserving the application's existing trip-listing functionality.

Skills Demonstrated

  • Algorithm design and implementation
  • Weighted scoring and ranking
  • Data filtering and sorting
  • Structured data using TypeScript interfaces
  • Evaluation of algorithm efficiency
  • Integration with an existing full-stack application
  • Testing and validation of enhanced functionality
