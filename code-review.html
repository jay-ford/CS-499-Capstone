The informal code review examines the original Travlr Getaways application and identifies opportunities for improvement prior to implementing the three capstone enhancements.

The code review evaluates the application in the three areas represented throughout the CS 499 Capstone project: software design and engineering, algorithms and data structures, and databases. The review discusses the existing functionality of the application, analyzes areas that can be improved, and explains the planned enhancements.
