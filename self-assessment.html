Completing the Computer Science program and developing this ePortfolio have given me the opportunity to reflect on how my technical abilities and approach to problem-solving have developed. When I began the program, my goal was to expand my understanding of technology and develop skills that could complement my professional experience. Throughout the program, I gained experience in software development, algorithms and data structures, databases, security, testing, and full-stack development. More importantly, I became more confident in my ability to evaluate a problem, identify possible solutions, implement a solution, and test the results. This ePortfolio brings those skills together and demonstrates my growth as a computer science professional.

Communication and collaboration have been important parts of that development. My coursework required me to explain technical decisions through documentation, reports, presentations, code comments, and project materials intended for different audiences. I learned that technical knowledge is most valuable when it can be communicated clearly to developers, stakeholders, and users. Although many of my academic projects were completed independently, I also developed skills that support collaborative software development, including version control, code reviews, iterative development, documentation, and writing maintainable code. These practices allow developers and stakeholders to understand design decisions, evaluate solutions, and contribute to informed decision-making.

My coursework also strengthened my abilities in software engineering, algorithms, databases, and security. Software engineering taught me to consider modularity, separation of concerns, maintainability, testing, and code reuse rather than focusing only on whether an application works. Algorithms and data structures strengthened my ability to organize information, develop logical solutions, evaluate efficiency, and consider trade-offs between different approaches. Database coursework provided experience with relational and NoSQL systems and reinforced the importance of data integrity, validation, querying, and performance. Security coursework taught me to consider authentication, authorization, input validation, data protection, and potential vulnerabilities throughout the development process rather than treating security as something added after an application is complete.

My experience in the Computer Science program extends beyond the artifact presented in this portfolio. Coursework exposed me to software testing and quality assurance, operating environments, secure coding, full-stack development, databases, algorithms, and other areas of computing. Working across these subjects helped me understand that effective software solutions depend on more than programming alone. They require appropriate algorithms, reliable data storage, security controls, testing, documentation, communication, and consideration of the people who will use and maintain the software.

The primary artifact in this ePortfolio is the Travlr Getaways full-stack web application, originally developed during CS 465: Full Stack Development. Revisiting the application during CS 499 allowed me to evaluate an existing project from a more experienced perspective and implement focused improvements in the three required areas of the capstone. The Category One enhancement demonstrates software design and engineering by converting the remaining static customer-facing pages into reusable Handlebars templates and shared components, improving consistency and maintainability while preserving existing functionality.

The Category Two enhancement demonstrates algorithms and data structures through a personalized trip recommendation feature. I developed a weighted scoring algorithm that evaluates trips according to user preferences, calculates matching scores, filters results, and ranks recommendations. This enhancement demonstrates how algorithmic principles and structured data can be applied to provide practical value within an existing application.

The Category Three enhancement demonstrates database development by strengthening the MongoDB and Mongoose portions of the application. I improved schema validation, database indexing, error handling, and database seed operations to strengthen data integrity, consistency, and maintainability. This work also reinforced the importance of a security mindset because validation, normalization, uniqueness constraints, and consistent error handling help control the quality and integrity of information entering the application.

Together, these enhancements demonstrate how different areas of computer science contribute to a complete software solution. The first improves the application's structure and maintainability, the second introduces algorithmic functionality that provides additional value to users, and the third strengthens the database foundation supporting the application. The original artifact, code review, enhancement narratives, and completed source code provide evidence not only of the technical work I completed but also of the decisions, testing, and learning that occurred throughout the capstone.

Completing the Computer Science program has changed the way I approach technical problems and increased my confidence as a software developer. My original goal was to develop technical skills that could complement my existing professional experience, and the program has provided me with a foundation that can be applied in my current work while also creating opportunities for continued growth in computer science. This ePortfolio represents my ability to evaluate existing software, communicate technical information, design and implement computing solutions, work with algorithms and databases, consider security and data integrity, test solutions, and improve software while maintaining existing functionality. It also represents a foundation that I intend to continue building upon as technology and my professional goals evolve.
