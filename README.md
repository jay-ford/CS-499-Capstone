# Category One Enhancement – Software Design and Engineering

This branch contains the **Category One Enhancement** completed for my **CS 499 Computer Science Capstone** using the Travlr Getaways full-stack web application originally developed for **CS-465 Full Stack Development with MEAN**.

The purpose of this enhancement was to improve the application's software design, maintainability, consistency, and organization while preserving its existing functionality.

---

## Enhancement Overview

The original Travlr Getaways application contained several static HTML pages in the customer-facing portion of the application. During the original CS-465 project, the travel page was converted to use Handlebars.

For the Category One enhancement, the remaining static pages were converted into reusable **Handlebars templates**, including:

- Index
- About
- Rooms
- Meals
- News
- Contact

A shared layout using common header and footer partials was also implemented to reduce duplicated code and provide a more consistent structure throughout the application.

---

## Software Design and Engineering Improvements

This enhancement demonstrates software design and engineering principles through:

- Conversion of static HTML pages to reusable Handlebars templates
- Implementation of shared header and footer partials
- Reduction of duplicated markup
- Improved code organization
- Improved maintainability and consistency
- Preservation of existing application functionality

These changes provide a stronger foundation for maintaining and extending the customer-facing portion of the Travlr Getaways application.
