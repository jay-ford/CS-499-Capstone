CS 499 Computer Science Capstone
Travlr Getaways Enhancement Project

This repository contains my CS 499 Capstone project based on the original
Travlr Getaways application developed in CS 465. The project demonstrates
three progressive enhancements:

• Category One – Software Design and Engineering
• Category Two – Algorithms and Data Structures
• Category Three – Databases

Each enhancement builds upon the previous version while preserving the
original artifact for comparison.
