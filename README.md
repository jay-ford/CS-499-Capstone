# Travlr Getaways – Original Artifact

This branch contains the original version of the Travlr Getaways full-stack web application developed for CS-465 Full Stack Development I.

The application was selected as the primary artifact for my CS 499 Computer Science Capstone and serves as the baseline for the enhancements completed during the capstone.

The original application uses the MEAN stack, including:

- MongoDB
- Express.js
- Angular
- Node.js

This branch preserves the original artifact before the CS 499 enhancements were implemented.
