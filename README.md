Travlr Getaways – Final Artifact

This branch contains the final enhanced version of the Travlr Getaways application developed for my CS 499 Computer Science Capstone. The final artifact builds on the original application created for CS-465 Full Stack Development with MEAN and incorporates the completed enhancements in software design and engineering, algorithms and data structures, and databases.

The purpose of the final artifact is to demonstrate the progression of the original application into a more maintainable, functional, and robust full-stack application while showcasing skills developed throughout the Computer Science program.

Final Artifact Enhancements
Software Design and Engineering

The Software Design and Engineering enhancement improved the structure and maintainability of the customer-facing portion of the application.

The remaining static HTML pages were converted into reusable Handlebars templates, including:

Index
About
Rooms
Meals
News
Contact

A shared layout using common header and footer partials was also implemented to reduce duplicated code and improve consistency throughout the application.

Algorithms and Data Structures

The Algorithms and Data Structures enhancement introduced a personalized trip recommendation engine.

Users can enter travel preferences such as:

Resort
Maximum price
Maximum trip duration

The recommendation algorithm evaluates the available trips against the selected preferences, assigns matching criteria, and ranks the results to provide relevant trip recommendations.

The final artifact includes an expanded six-trip dataset to demonstrate and test the recommendation functionality across different combinations of travel preferences.

Databases

The Database enhancement strengthened the application's MongoDB and Mongoose data layer.

Improvements include:

Expanded schema validation
Improved data integrity
Database indexing
Improved database operations
Enhanced error handling
More reliable data retrieval

These improvements were implemented while maintaining compatibility with the application's existing functionality.

The completed artifact integrates all three CS 499 enhancement categories into a single version of the Travlr Getaways application.
