Artifact Overview

The original artifact is the Travlr Getaways full-stack web application, originally developed during CS 465: Full Stack Development I. The application was developed using the MEAN stack, which incorporates MongoDB, Express, Angular, and Node.js to provide both customer-facing and administrative functionality.

This version represents the application before the CS 499 capstone enhancements were implemented. It serves as the baseline for demonstrating the improvements completed in software design and engineering, algorithms and data structures, and databases.
